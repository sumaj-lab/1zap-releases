# 1Zap

Fast, reliable download manager for Windows that stays fast to the very last byte.

## Download

Get the installer from the [latest release](https://github.com/sumaj-lab/1zap-releases/releases/latest)
(`1Zap_<version>_x64-setup.exe`), or install it with winget:

```
winget install 1Zap.1Zap
```

1Zap updates itself: it checks this page for new versions and installs them only when you say so.

## Windows says "Windows protected your PC"

New versions aren't known to SmartScreen yet. Click **More info**, then **Run anyway**. Only download
1Zap from this page (or winget).

## Problems or ideas

Open an [issue](https://github.com/sumaj-lab/1zap-releases/issues).

This repository holds only the released installers and the update file, not the source code.
